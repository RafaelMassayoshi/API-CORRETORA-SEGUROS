# API de Gestão para Corretores de Seguros

API backend para gestão de clientes, vendas e apólices de seguros.  

> Atualmente a versão inicial permite apenas o cadastro de **clientes pessoa física (PF)**

---

## Funcionalidades

### Funcionalidades implementadas
- Cadastro de clientes pessoa física (PF)
- Validação de dados do cliente (nome, cpf, estado civil, sexo, data de nascimento, renda)
- Normalização de dados (maiusculas, remoção de espaços)
  
### Funcionalidades planejadas
- Cadastro de clientes pessoa jurídica (PJ)
- Registro de apólices de seguros
- Controle de vendas e comissões
- Relatórios de clientes, apólices e vendas

---

## Tecnologias

- Node.js
- Express.js
- MySQL
- JavaScript (ES6+)
